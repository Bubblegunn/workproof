# Evidence of authored work in a private client repository

The source code is private and is not included. This package holds a report of one person's commit history (no code, no file paths, no email addresses) and a machine-readable copy carrying a hash.

- workproof-report.md: readable report
- workproof-report.json: same figures, with a hash

Scope: commits are counted by author date, from 7 Nov 2013 to 22 Aug 2015. Three author identities are counted as one person (63 of 131 non-merge commits in that period); 13 merge commits are not counted. Two of the three were matched by a rule and are listed for the reader's confirmation.

Limits: history can be rewritten before a report is made, and the figures show activity and surviving lines, not quality, review, design or mentoring. Pair this with a letter from someone who worked on the project.

A reader with repository access can check it; see HOW-TO-VERIFY.txt.
