## Departures from the frozen protocol and incidents

1. The run queue died once part-way (cause not found; another session shares the machine and its shim). It was restarted for the cells without a DONE marker.
2. At 23:29 the shared SDK shim switched its active key file to a second key (own organisation credit) while the queue ran. With the temporary HOME the shim could not read it, so 24 public OURS cells and 6 held-out cells failed before any model call (no cost, never graded). The run wrapper then linked the key file into each temporary HOME (a link, no copy) and the failed cells were re-run. Cells run after the switch used the second key, earlier cells the first (apiKeySource ANTHROPIC_API_KEY in both).
3. The first grading round was made while those failed OURS public cells were present, and the held-out packets were not built (wrong tasks path). It was discarded and grading was redone once for all arms. Both discarded folders are listed in `grades/discarded/README.md`; their files are not on disk any more (empty folders), so they cannot be published.
4. The run wrapper had a wrong run-folder path in its 429 detection during the first queue. No 429 occurred; the shim ledger and the results show none.
5. The controller issued `pkill` commands for its own queue that may have matched processes of other sessions.
6. Three unscored diagnosis runs of the new code on seen held-out b tasks (H1, H2, H3; 1 run each) were made before the protocol freeze.
7. The public rival cells are deep-round transcripts, regraded together with the new OURS cells (as frozen). The owner's sentence "no cell is reused" therefore holds only for held-out set c and for OURS.
8. The diagnosis corrected two statements of the deep-round report: the H3 hook did match, and the missed H2 criterion was a per-row line count.
9. The controller read the held-out c README (hazard summary) after the writer had finished. Nothing derived from it reached the implementer or the reviewer.
10. Whole-disk `find` scans by agents were killed by a reaper script (as in the deep round).
11. Harness changes: `assemble.py` lists changed files by comparison with the pristine fixture for set c (`effaed4`), and the harness file `portfolio-bank.md` is excluded from that listing (`5468312`).
