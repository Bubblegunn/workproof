I maintain co, the generator-based async control-flow library that TJ Holowaychuk created in 2013. By current git blame, about half of the lines in the repository (roughly 630 of 1,220, excluding History.md and LICENSE) are mine, including about 52% of index.js and most of the Readme and tests. TJ still authored about 36%, and the rest comes from outside contributors. By commit count my share is smaller: 63 of 230 non-merge commits, about 27%, versus TJ's 90. My main contributions are the 2014 rewrite to a promise-based implementation (v4.0), object and array yielding, error-handling fixes, test coverage, CI, and releases from 3.0 through 4.6. I did not create the library or its original design.
