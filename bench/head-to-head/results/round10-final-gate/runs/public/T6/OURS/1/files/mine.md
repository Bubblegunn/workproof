## Which addresses are counted

Counted as the same person: 1 other address, because the rules matched: a GitHub noreply address whose login matches the name or the address in git config. This is a rule, not proof: it can be wrong, and --no-merge-identities counts only the configured address and addresses with the same name.

## What this does not show

Commits measure activity and surviving lines measure what lasted; neither measures quality, review or design. Run `npx workproof` and `npx workproof verify` for a report a reader can check.
