## What the library is

The repository is the team's Go logging library. It is a copy (a "fork") of the open-source library *logrus*. The history shows it was cloned from `github.com/sirupsen/logrus`, and the module name in `go.mod` is still `github.com/sirupsen/logrus`. Most of the code and history came from the open-source project and its many outside contributors. This statement covers only the commits added on top of that history.
