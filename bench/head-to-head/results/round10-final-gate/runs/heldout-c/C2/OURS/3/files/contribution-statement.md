## How to read the table

- **Authored.** Commits `4e129b6`, `735aaa3`, `ba8bfca` and `084addb` list Tomás Alvarez as both author and committer.
- **Generated code.** The 1,803 lines in `735aaa3` were produced by a tool, and the file header says "Code generated by go generate; DO NOT EDIT". The commit adds the output of the generator. Line counts for that commit therefore do not measure hand-written work, and the file should not be counted as 1,803 lines of hand-written code.
- **File move.** In `084addb`, git records the two files as renamed with no change to their contents. It was a reorganisation of the project's folders, not new code.
- **Co-authorship.** In `dbd09a0` the author is Wei Zhang. The commit message has the line "Co-authored-by: Tomás Alvarez". Git does not record how much of that commit is his, so no share is claimed.
- **Line counts** are lines added, as reported by git. They show size only and do not measure quality or difficulty.
