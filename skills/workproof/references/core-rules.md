# workproof core rules

Out of scope: do the task, add one scope line, no refusal.

1. Identity (own work): same-person addresses/names by a stated rule are included, listed "included: <rule>, please confirm", never dropped; ask once at the end, no pause; addresses in chat only.
2. Window: commits authored before the window (rebase/replay) are outside; say author date used.
3. Deliverables: distinct user-visible work; merges, reverts, vendored, generated, whitespace/formatter commits go in a "not counted" list with reasons; a total names its filter.
4. Audience: non-technical reader: no commands, code, file, branch or tool names in the body; source tags, verify command go in chat and a sidecar; tool files in ./evidence/ (`--out evidence/...`) unless the user names a file.
5. Counts: run `npx workproof figures` first, write each figure with its printed label; `--author` for the person named; figures unknown (older version): read-only git, stated filter. Every number (basis and footer lines too) is the filtered count: sessions unique, in window, on the named work; a raw file count is never a session count (exports: `sessions --dir <folder> --since D --until D`, count the `sessionRows` kept); not computed is not zero, write no number. First/last/gap/month statements come from a list whose rows equal the printed figure, else find the dropped row; calendar-date bounds, no hand-written T23:59:59 end. After writing run `figures --doc <file>`; fix or label any number matching no computed figure.
6. Provenance: read headers of large added files (licence/source). Lines written = authored in window minus third-party and formatter/whitespace-only (re-measure ignoring whitespace); reverted work stays in, listed reverted. Hand figure differing from the tool figure for the same filter: state both, which is raw, why. A delivered-only figure gets its own label and does not replace lines written.
7. Others' claims (candidate, contractor, auditor): read-only git, not figures; identity is what they state, the same name on another address is a separate unconfirmed person, named, kept out of every figure; say if an address is organisational or personal (by kind) and that it cannot prove an employer; ownership by surviving lines (`git blame -w -M -C`, generated files out; others' work only); history shows what, who, when, not time or quality; per item author, branch, date: what holds or does not; what history cannot decide is "not verifiable here" (name the outside source), kept apart from disproved and misleading; limits, next step; the Verdict line of `workproof verdict` is allowed.
8. Dates: author versus committer date; flag future dates, omit from dated lists.
9. Review evidence: one row per ordinary (not merge) commit; list merges (`git log --merges --full-history`) and read each full message; a merge-level approval covers its branch commits, labelled weaker; never state what you did not read.
