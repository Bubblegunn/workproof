# workproof core rules

Out of scope: do the task, add one scope line, no refusal.

1. Identity (own work): same-person addresses/names by a stated rule are included, listed "included: <rule>, please confirm", never dropped; ask once at the end; addresses in chat only.
2. Window: commits authored before the window (rebase/replay) are outside; say author date used.
3. Deliverables: distinct user-visible work; merges, reverts, vendored, generated, whitespace/formatter commits go in a "not counted" list with reasons; a total names its filter; also each person's commit count. Work the person joined but did not author (pair session, co-author trailer) is its own row, real author named.
4. Audience: non-technical reader: no commands, code, file, branch or tool names in the body; source tags, verify command go in chat and a sidecar; tool files in ./evidence/ (`--out evidence/...`) unless the user names a file. A 7-character sha, a date and an author name are not tool names: when the user asks for "the matching commit", put them in the body; only commands go in the sidecar.
5. Counts: run `npx workproof figures` first, write each figure with its printed label; `--author` for the person named (one address leaves other addresses out; for the user's own work add the listed identity candidates, labelled); figures unknown (older version): read-only git, stated filter. Every number (basis and footer lines too) is the filtered count: sessions unique, in window, on the named work; a raw file count is never a session count (exports: `sessions --dir <folder> --since D --until D`, count the `sessionRows` kept); not computed is not zero, write no number. First/last/gap/month statements come from a list whose rows equal the printed figure, else find the dropped row; calendar-date bounds, no hand-written T23:59:59 end. After writing run `figures --doc <file>`; fix or label any number matching no computed figure.
6. Provenance: read headers of large added files (licence/source). Lines written = authored in window minus third-party and formatter/whitespace-only (re-measure ignoring whitespace); reverted work stays in lines written, listed under "reverted", not as shipped. `figures` prints "lines written, net of exclusions" and the excluded lines by reason: quote them, do not re-derive. Hand figure differing from the tool figure for the same filter: state both, which is raw, why. A delivered-only figure gets its own label and does not replace lines written.
7. Others' claims (candidate, contractor, auditor): read-only git, not figures; identity: a noreply address of the same login or name, the claimant's own second address, or the same full name at the same organisation or on a personal mailbox, is the same person (one row, merged and split figures, "included: <rule>, please confirm"); the same name at unrelated organisations is a separate unconfirmed person, kept out of every figure; trailers (Co-authored-by, Reviewed-by, any case) are read on all commits in the window, others' too; self-credit and Signed-off-by are no help; AUTHORS names with no commits: named, no share; a different spelling is another person; say if an address is organisational or personal; it cannot prove an employer; ownership: `npx workproof owner --path P --claim NAME` (surviving lines, whitespace and moves ignored); history shows what, who, when; per item author, branch, date: what holds or does not (three states: holds, holds with an exception, does not hold; only the first is clean, count them apart); for the claimed scope list author and committer separately (a committer alone is not the claimant's work); what history cannot decide is "not verifiable here" (name the outside source), apart from disproved and misleading; limits, next step; `workproof verdict` Verdict line allowed.
8. Dates: author versus committer date; flag future dates, omit from dated lists.
9. Review evidence: `npx workproof reviews --path P --since D --until D --format csv --out F` (one row per ordinary commit, merges read; a merge-level approval covers its branch commits, labelled weaker); never state what you did not read.
10. Who did most / concentration: give the commit share and the line share (`figures` prints both and the largest commit) and say when one commit holds over half of the lines.
