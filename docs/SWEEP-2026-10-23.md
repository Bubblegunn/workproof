## Findings

1. **bug** - `verify` (and so `verdict`) fails on a report the tool just wrote. Repos: tj/commander.js ba6d13d, torvalds/uemacs 325a8e9, sinatra/sinatra cb22afd, psf/requests 611c616, django/django 512b92a. Command: `workproof --repo R --author <top email> --out r` then `workproof verify r.json --repo R --fingerprint-key K`. Expected: all figures reproduce. Actual: exit 1, 7 figures differ (commitShare, cadence, footprint, commitSize, absenceFactor, survivingLines, survivalByCohort); commander: 501 commits in the report, 506 on verify. `verdict` on sinatra says "Do not trust as is". It happened in 5 of the 13 repos, each with another address under the same author name (1, 2, 2, 3, 1 other addresses). Cause (read, not tested): the explicit `--author <email>` is exact (analyse.ts), but the report hides emails and stores only names, and `verify.ts:66` resolves the identity by name, which also takes in the other addresses. The comment at `verify.ts:61` assumes a merged identity, which holds only for the config-derived path. Not tested: `--emails` runs.
2. **bug (cause unknown)** - psf/requests 611c616: `figures --repo R --author me@kennethreitz.com --json` gives "all authors, non-merge commits" 4882; plain git gives 4883 (`git log HEAD --no-merges`, author date, no window). Same difference with `--author "<name>"` and in the report (`commitShare.total` 2823 vs 2824). Cause not investigated.
3. **bug (cause unknown)** - expressjs/express 0dee2c5: `whitespace-only commits` is 31 for tj@vision-media.ca; reference (raw added+deleted > 0 and `-w` totals both 0) gives 32. Cause not investigated; src/figures.ts around the `wsOnly` filter compares files by path between the raw and `-w` runs, which can differ for renames (unchecked).
4. **unresolved** - psf/requests: surviving-line check with `--no-exclusions --sample 1` gives linesAttributed 28186 and my `git blame -w -M` reference 28225 (diff 39). Also file counts differ by 2 to 6 in click (170 vs 176), sinatra (288 vs 290), express (211 vs 214), requests (123 vs 125). For the file counts, the cause is most likely empty text files, which the tool lists and `git grep` does not; the script now adds empty files and symlinks (commander's 3 symlinks explained its first 3-file difference) but the sweep was not re-run, so this is unconfirmed. The 39-line difference on requests is unexplained.
5. **slow** - django/django 512b92a (35,049 commits, 279 MB): default report 71 s, verify 98 s, verdict 85 s, mine 74 s, windowed report 78 s, report without --author 35 s, mine without --author 68 s. Figures took under 30 s. All other repos done were under 30 s per command (flask figures about 6 s on 132 commits). Cause not investigated.
